# Cici’s personal portfolio

A small TypeScript + Vite website. It keeps portfolio content in typed data, styling in CSS, and browser behavior in one TypeScript file.

## Start on your computer

Install Node.js 24 LTS, then open this folder in VS Code. In its terminal:

```powershell
npm ci
npm run dev
```

Open the local URL printed by Vite. The development server updates the page when you save a source file.

## Understand the files

| File | Responsibility | First thing to try |
| --- | --- | --- |
| `index.html` | Page views, navigation, introduction, and static text | Edit one sentence in your introduction |
| `src/styles.css` | Colors, spacing, typography, responsive layout | Change `--accent` and inspect the result |
| `src/types.ts` | TypeScript interfaces describing projects and experience | Read `Project` and find each field in the data |
| `src/data.ts` | The project and experience content | Add a repository link to one project |
| `src/main.ts` | Render entries, handle filters, and switch page views | Follow a click from `addEventListener` to `updateProjects` |
| `package.json` | Dependencies and terminal commands | Find the command behind `npm run dev` |
| `package-lock.json` | Exact installed dependency versions | Keep it in Git so installs are reproducible |
| `vite.config.ts` | Build configuration | Notice the relative asset base |
| `.github/workflows/deploy.yml` | Build and deploy on GitHub | Read checkout → install → build → deploy |

`dist/` is generated by the build. Edit source files, not `dist/`.

## Commands

- `npm run dev`: start the local development server.
- `npm run check`: check TypeScript types without producing output files.
- `npm run build`: check types and produce the static website in `dist/`.
- `npm run preview`: serve the built files locally to inspect the production output.

## Publish on GitHub Pages

Your two repositories serve different purposes:

- `CiciAa777/CiciAa777`: the short GitHub profile `README.md`.
- `CiciAa777/CiciAa777.github.io`: this website’s source code.

Create the website repository, copy the contents of this project into it, and push to `main`. In Settings → Pages, choose **GitHub Actions** as the source. The included workflow builds and publishes the site. Its expected public URL is `https://ciciaa777.github.io/`, after a successful deployment.

Keep the `.github` folder: it contains the publishing workflow. The `.openai` folder belongs to the private preview and is omitted from the portable source ZIP.

Before public launch, add your preferred email, LinkedIn, résumé, and profile photo; verify personal contributions, dates, and reported evaluation results.

Reference: [Vite deployment guide](https://vite.dev/guide/static-deploy.html#github-pages).

## Design and navigation

The current design closely follows the supplied Angelina portfolio reference: white background, pill navigation, bold system typography, purple–blue accents, oval portrait area, experience timelines, and rounded project cards. All biography and experience content is Cici’s. The portrait is an initials placeholder; replace its HTML with your own image when ready. Featured project covers are typography, not screenshots.

Each navigation link uses a hash such as `#about`. `navigate()` in `src/main.ts` shows that view, updates the active link and browser title, and handles back/forward navigation. This avoids server routing requirements on GitHub Pages.
